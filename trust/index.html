Security practices

Access & authentication

  • Role-based access enforced server-side on every action
  • Strong password hashing (PBKDF2), timing-safe login
  • Opaque, expiring, revocable sessions
  • Step-up multi-factor authentication for sensitive operations

Data protection

  • Encryption in transit (TLS) and at rest
  • Tenant secrets AES-GCM encrypted at rest with a shared, versioned key + per-tenant additional-authenticated-data (AAD) binding
  • Strict tenant isolation; all access via the application layer
  • Identity documents in private, capability-gated storage

Application security

  • 100% parameterized queries (no SQL injection surface)
  • Output encoding + CSP; CSRF protection; strict CORS
  • SSRF protections; rate limiting; signed webhooks
  • CI security/quality gates on every deploy

Payments

  • Card data handled by Stripe (PCI Level 1)
  • Card numbers never stored by Atlas
  • Server-authoritative pricing, caps, and credits

Data & privacy

You (and your renters) own your data. Atlas acts as a processor for the personal data you collect through the platform. We provide operator-level data export and deletion and assist with privacy rights (access, deletion, correction, opt-out); for a Tenant's end customers, these are currently fulfilled through the Tenant (a self-service end-customer request portal and Global Privacy Control handling are in progress). We never sell personal data. Precise geolocation and identity documents receive heightened safeguards and are used only for their stated purpose.
